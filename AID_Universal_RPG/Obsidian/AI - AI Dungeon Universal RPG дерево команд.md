# Universal RPG — дерево команд

Команды вводятся отдельным сообщением в режиме Do. `|` разделяет аргументы, `ID` означает номер записи. Подробный синтаксис и ограничения: [[AI - AI Dungeon все команды]].

- **Справка, состояние и диагностика**
  - `:help` / `:help all` / `:help Тема` — общий список или справка по теме команды.
  - `:status` — лист персонажа, ресурсов, инвентаря и режимов.
  - `:effects` — журнал последних изменений от автоматического учёта.
  - `:debug on/off` — включить или выключить подробную диагностику.
  - `:debug status` — показать активные режимы и счётчики бросков.
  - `:debug last` — показать последнее решение судьи или бросок.
- **Анкета и начальная настройка**
  - `:setup` / `:setup template` / `:setup show` — показать общий шаблон настроек.
  - `:setup help` — правила заполнения блока.
  - `:setup rules` — шаблон режимов и переключателей.
  - `:setup hero` — шаблон героя и характеристик.
  - `:setup skills` — шаблон стандартных и пользовательских навыков.
  - `:setup resources` — шаблон даты, места, денег, потребностей и предметов.
  - `:setup` + строки `§ключ=значение` + `§:apply` — применить настройки единым блоком:
    - `budget=creation/free` — режим бюджета создания или свободного редактирования.
    - `auto=narrative/classic/smart/off`, `judge_combo=simple/weighted/detailed`, `fallback=safe/story/strict` — режим судьи.
    - `debug`, `inventory`, `needs`, `combat`, `economy`, `xp`, `magic`, `editor`, `ledger` = `on/off` — переключатели модулей.
    - `xp_speed=slow/normal/fast/число`, `xp_mode=instant/rest/manual` — скорость и момент повышения.
    - `name`, `gender`, `age`, `job`, `bio`, `dream` — сведения героя.
    - `stat.Название`, `skill.Название`, `custom.Название` — характеристики, стандартные и пользовательские навыки.
    - `year`, `month`, `day`, `time`, `place` — календарь, часы и место.
    - `money`, `debt`, `maxhp`, `maxstamina`, `hp`, `stamina`, `hunger`, `thirst`, `fatigue` — ресурсы и потребности.
    - `item.Название` — количество предмета.
- **Герой, характеристики и навыки**
  - `:char` / `:char show` / `:char info` — показать героя, черновик или подробности.
  - `:char create` — начать черновик нового героя.
    - `:char name/gender/age/job Значение` — заполнить основные поля черновика.
    - `:char stat Название Число` / `:char skill Название Число` — распределить стартовые очки.
    - `:char done` — сохранить черновик героя.
    - `:char cancel` — отменить черновик.
  - `:char bio` / `:char background` — показать биографию.
    - `:char bio Текст` / `:char bio set Текст` — заменить биографию.
    - `:char bio add Текст` — дополнить биографию.
    - `:char bio clear confirm` — очистить биографию.
    - `:char background ...` — синоним тех же действий.
  - `:char dream` / `:char goal` — показать мечту.
    - `:char dream Текст` / `:char dream set Текст` — заменить мечту.
    - `:char dream clear confirm` — очистить мечту.
    - `:char goal Текст` — старый синоним записи мечты.
  - `:char help` — справка по анкете.
  - `:stat list/help` — справка и перечень характеристик.
  - `:stat Название Число` — вручную установить характеристику.
  - `:skill list/help` — справка и перечень навыков.
  - `:skill Название Число` — вручную установить уровень навыка.
  - `:skill add Название | Характеристика [| Ключи]` — создать пользовательский навык.
  - `:skill info Название` — показать параметры навыка.
  - `:skill attr Название | Характеристика` — изменить его базовую характеристику.
  - `:skill bind Название | Ключи` — заменить слова для распознавания навыка.
  - `:skill remove/delete Название` — удалить пользовательский навык.
- **Броски и судья**
  - `:roll Грани` — бросить кубик с заданным числом граней.
  - `:check preview Описание [| Цель]` — подобрать варианты проверки без броска.
  - `:check Описание [| Цель]` — выполнить свободную проверку; при нескольких вариантах запросить выбор.
  - `:check choose N` / `:check cancel` — выбрать предложенный вариант или отменить его.
  - `:check Характеристика [DC] [Навык] | Действие` — ручная проверка с заданной или подобранной сложностью.
  - `:auto on/off` — включить последний выбранный режим или отключить автопроверки.
  - `:auto classic/smart/narrative/cautious` — выбрать алгоритм автосудьи.
  - `:judge` / `:judge help` — режим сочетания навыков и справка.
    - `:judge combo simple/weighted/detailed` — выбрать способ комбинированной проверки.
    - `:judge override Характеристика | Навык` — назначить пару для следующей автопроверки; навык может быть пустым.
    - `:judge clear` — отменить ожидающее переопределение.
    - `:judge last` — показать последнее решение.
  - `:fallback` — показать резервный режим обработки ответа модели.
    - `:fallback safe/story/strict` — выбрать поведение при ошибке формата ответа.
  - `:editor on/off` — контроль формата ответа рассказчика.
  - `:ledger on/off` — учёт структурированных изменений в совместимом режиме.
  - `:magic on/off` — разрешить или запретить магию.
- **Опыт и временные эффекты**
  - `:xp` / `:xp help` — сводка опыта или справка.
  - `:xp on/off` — включить или приостановить развитие.
  - `:xp speed slow/normal/fast/число` — выбрать множитель опыта.
  - `:xp mode instant/rest/manual` — выбрать момент повышения.
  - `:xp skill Название` / `:xp stat Название` — показать прогресс навыка или характеристики.
  - `:xp apply` — применить готовые повышения.
  - `:xp log` — показать историю развития.
  - `:mod` / `:mod list/status/help` — показать активные модификаторы d20 или справку.
    - `:mod add Цель[, Цель] | +2/-2 | Минуты | Причина` — назначить временный бонус или штраф.
    - `:mod remove/delete ID` — снять один эффект.
    - `:mod clear confirm` — снять все эффекты.
  - `:modifiers` / `:modifiers list/status/help/add .../remove/delete ID/clear confirm` — старый синоним команд `:mod`.
  - `:buff` / `:debuff` + `list/status/help/remove ID/delete ID/clear confirm` — просмотр и снятие старых положительных/отрицательных эффектов; добавление через них отключено.
- **Дата, время, место и потребности**
  - `:date` / `:date show` — показать игровой календарь и часы.
    - `:date set Год Месяц День [HH:MM]` — установить дату без учёта прошедшего времени.
    - `:date advance N` / `:date next N` — продвинуть дату на N дней с учётом потребностей.
  - `:time Минуты` — продвинуть часы и учесть потребности.
    - `:time set HH:MM` — установить часы без учёта прошедшего времени.
  - `:place Название` — указать текущее место героя.
  - `:rest Минуты` — отдохнуть или поспать; долгий отдых может применить XP.
  - `:needs on/off` — включить или выключить автоматический рост потребностей.
    - `:needs status/why` — показать показатели и темп изменения.
    - `:needs eat/drink` — вручную подтвердить еду или питьё.
    - `:needs hunger/thirst/fatigue N` / `:needs set hunger/thirst/fatigue N` — вручную установить показатель 0–100.
  - `:combat on/off` — включить или выключить автоматические последствия боя.
  - `:hp +N/-N` / `:stamina +N/-N` — вручную изменить здоровье или выносливость.
- **Деньги и предметы**
  - `:economy on/off` — включить или выключить учёт явных финансовых действий игрока.
  - `:money +Сумма/-Сумма` — вручную изменить баланс.
  - `:debt` / `:debt show/status` — показать долг и баланс.
    - `:debt log/history` — показать финансовые операции.
    - `:debt add Сумма` — увеличить долг.
    - `:debt pay Сумма` — погасить долг с баланса.
    - `:debt set Сумма` — установить абсолютный размер долга.
  - `:inventory on/off` — включить или выключить строгую проверку наличия предметов.
  - `:give Предмет [Количество]` / `:take Предмет [Количество]` — добавить или убрать предмет.
  - `:rename Старое имя | Новое имя` — переименовать предмет с сохранением количества.
  - `:use Предмет [| Действие]` — проверить наличие предмета и передать действие рассказчику.
- **Квесты и предложения рассказчика**
  - `:quest` / `:quest list [all/active/done/failed/cancelled]` — показать задания по статусу.
    - `:quest add Название [| Описание]` — создать задание.
    - `:quest info ID` — открыть полную запись.
    - `:quest status ID active/done/failed/cancelled` — изменить статус.
    - `:quest edit ID | Название [| Описание]` — изменить название и описание.
    - `:quest due ID | Год Месяц День [HH:MM]` — установить срок.
    - `:quest due ID clear` — удалить срок.
    - `:quest remove ID confirm` — удалить задание.
    - `:quest help` — справка по квестам.
  - `:review` / `:review list/all` — показать расхождения рассказчика с балансом и статусами заданий.
    - `:review dismiss/remove ID` — убрать одно напоминание без изменения игры.
    - `:review clear confirm` — убрать все напоминания.
    - `:review help` — справка по проверке.
  - `:note ...` / `:notes ...` — устаревшие команды: выводят подсказку перейти на `;mem fact` или `;mem event`; заметки в RPG не редактируют.
- **Обмен с Memory Engine**
  - `:aidm` / `:aidm help` — справка по экспорту героя.
  - `:aidm status` — проверить готовность снимка и наличие обменной карточки.
  - `:aidm export` — создать или обновить обменную Story Card; импорт в Memory Engine запускается отдельно.
- **Пакеты и обслуживание**
  - `:batch help` / `:batch template` / `:batch categories` — справка и список шаблонов.
  - `:batch template hero/skills/inventory/resources/modifiers/time/quests/rules/review` — получить шаблон пакета.
  - `:batch template notes` — устаревший шаблон заметок; показанные в нём команды `:note` больше не меняют память RPG.
  - `:batch` + строки `§:команда ...` + `§:apply` — применить несколько допустимых команд одним блоком.
  - `:rpg` / `:rpg help` — справка по обслуживанию.
    - `:rpg status` — показать состав сохранённого состояния.
    - `:rpg memory clear` / `:rpg memory clear confirm` — предпросмотр или очистка журналов и квестов.
    - `:rpg reset` / `:rpg reset confirm` — предпросмотр или полный сброс RPG.
    - `:rpg uninstall` / `:rpg uninstall confirm` — предпросмотр или удаление состояния RPG.

`§:apply` завершает блок `:setup` или `:batch`; отдельной игровой командой он не служит. RPG ведёт квесты и свой календарь, а сюжетные заметки хранятся в Memory Engine.
