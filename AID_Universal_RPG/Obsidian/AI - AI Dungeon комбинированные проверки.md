## Коротко

**Автоматический программный судья** выбирает характеристику и основной навык по действию, а не по первому совпадению. Он сравнивает совпавшие стандартные правила и ключевые слова пользовательских навыков. При наличии явно подходящего второго навыка может дать **максимум +1 к d20**. Сложные действия иногда требуют второго независимого броска. Это набор эвристик, **не полноценное понимание текста ИИ**.

Работает для `:auto narrative`, `:auto classic` и распознанных действий в `:auto cautious`. Для `:auto smart` при корректном JSON выбор производит модель; программный контекстный алгоритм применяется при резервном переходе к narrative. Простые ручные проверки `:check` сохраняют свой явно заданный выбор.

## Режимы

| Режим | Назначение |
|---|---|
| `simple` | Старая схема: первый подходящий стандартный шаблон или наиболее специфичный пользовательский ключ; один навык, характеристика по умолчанию |
| `weighted` | **По умолчанию**: сопоставление кандидатов по тексту и способу выполнения, при необходимости +1 от второго *прокачанного* навыка; один бросок |
| `detailed` | Как `weighted`, но при явно указанных двух независимых целях (например, вскрыть замок и избежать обнаружения охранником) делает **два броска** |

В `weighted` обычная фраза «незаметно вскрываю электронный замок рядом с охранником» приводит к основной проверке **Интеллект/Технологии**, с бонусом **+1 от Скрытности**, если её уровень ≥10. Этот единственный бросок определяет основное действие; бонус не гарантирует, что охранник не заметил героя.

В `detailed` на такую фразу при явном риске обнаружения будут отдельные проверки **Технологии** и **Скрытность**. Взлом может удаться, даже если охранник заметил персонажа, и наоборот. В остальных ситуациях остаётся одна проверка. Для подробного режима рекомендуются `:auto narrative` и `:debug on`.

## Контекстная характеристика

Связанная с навыком характеристика остаётся основной по умолчанию, но контекст может её поменять.

| Пример | Возможная характеристика и навык |
|---|---|
| «Рисую портрет с натуры, внимательно изучая лицо» | Восприятие / Рисование |
| «Рисую мелкие детали, требующие точных движений» | Ловкость / Рисование |
| «Придумываю необычный дизайн логотипа» | Смекалка / Рисование |
| «Применяю академическую технику рисунка» | Интеллект / Рисование |
| «Убеждаю логическими аргументами» | Интеллект / Переговоры |

Поддерживаются только заложенные контекстные маркеры — скрипт может неверно интерпретировать сложный или необычный оборот. При ошибке применяй одноразовое переопределение или `:check`.

## Команды

```text
:judge                          # текущий режим
:judge combo weighted           # контекстный выбор + помощь
:judge combo simple             # старый выбор
:judge combo detailed           # независимые дополнительные риски
:judge override Восприятие | Рисование
:judge clear                    # отменить одноразовое переопределение
:judge last                     # обоснование последнего выбора
:debug on                       # показать альтернативы, DC, бонусы и броски
:help judge                     # встроенная справка
```

`override` используется **один раз** при следующей автоматической проверке; не расходуется обычной командой `:status` или ручным `:check`. Проверка останется прежней по сложности DC, если изменить только характеристику/навык. `:judge clear` отменяет ожидающий выбор.

### Первоначальная настройка

В `:setup` и `:setup rules` добавлено поле (не удаляй символ-разделитель `§` при вставке):

```text
§judge_combo=weighted
```

Возможные значения: `simple`, `weighted`, `detailed`. Смена режима **не сбрасывает XP** и не изменяет уровни. Для уже начатой игры включается `weighted` по умолчанию.

## Опыт и XP

- В режиме `weighted` XP получает **только основной навык**, а практика — реально применённая характеристика. Вспомогательный навык даёт бонус, но **XP за поддержку не получает**.
- В режиме `detailed` каждый отдельный бросок считается полноценной проверкой и может дать XP своему навыку; защита от многократных повторов остаётся.
- Повышение основного навыка развивает его **базовую связанную характеристику**, даже если в данном действии применялась другая характеристика.

## Ограничения

Поиск по текстовым ключам остаётся эвристическим. Навык «Рисование» с ключами `рисун, рисован, рисовать` в этой версии дополнительно распознаёт распространённую форму «рисую». Проверка ключа `арт` не срабатывает внутри «картой». Подробный режим намеренно запускает второй бросок только при **явно распознанном независимом риске**, а не при любом упоминании двух навыков. Несколько несвязанных действий в одном сообщении по-прежнему могут быть интерпретированы неточно.

## Полуавтоматический подбор и выбор игроком (v2.29)

` :check preview ... ` отображает до трёх пар характеристика/навык и DC, затем `:check choose 1/2/3` выполняет ровно один бросок. Словесный способ («красотой», «логикой», «ловкостью») может изменить характеристику; фраза «используя навык Черчение» задаёт существующий навык явно. Для разных подходов к рисованию могут быть предложены разные характеристики. Этот выбор не переопределяет результаты уже выполненных бросков и не создаёт новые навыки. Полная инструкция: [[AI - AI Dungeon полуавтоматические проверки]].
