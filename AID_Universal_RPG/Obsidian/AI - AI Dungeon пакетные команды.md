# AI Dungeon — пакетные команды

> [!important] Полные шаблоны v2.25, совместимые с v2.29
> Шаблоны перечисляют **все разрешённые изменяющие операции своей категории по одному разу**. Они не предназначены для отправки без редактирования: **удали ненужные строки и замени ID**. При повторении операции скопируй нужную строку столько раз, сколько необходимо.

## Как работают пакеты

`:batch` исполняет обычные одиночные команды, каждая начинается с `:`. Перед каждой строкой, включая комментарии и финальное `:apply`, ставится **`§`** — AI Dungeon может склеивать переводы строк. Один пакет содержит **1–20 изменяющих команд** и не более **3800 символов**. Отправляется одним сообщением, обычно в режиме Story.

Изменения проверяются на временной копии состояния. При ошибке **весь текущий пакет отклоняется** без частичного применения. Ранее успешно применённые пакеты не откатываются. Комментарии `§#` не исполняются и не засчитываются в лимит команд, но учитываются в лимите символов.

**Символ `/` в комментариях с названиями навыков, типами заметок и статусами означает «или»**, а не разделитель синтаксиса RPG. Выбери **один** вариант, вставь его на место образца в строку команды, затем при необходимости скопируй строку для следующей записи. В самой исполняемой команде **нельзя оставлять список названий через `/`**.

> [!warning] Операции удаления
> Шаблоны содержат `remove` и `clear confirm`, поскольку это доступные операции. Они **действительно удаляют данные**. Перед отправкой удали строки, которые не хочешь исполнить, и проверь актуальные ID командами `:mod`, `:notes`, `:quest list all` или `:review`. Деструктивные действия лучше выполнять отдельным пакетом после резервной копии.

```text
:batch
§:stat Сила 12
§:skill Атлетика 10
§:money +100
§:apply
```

Команды управления хранилищем `:rpg memory clear confirm`, `:rpg reset confirm` и `:rpg uninstall confirm` выполняются **только отдельно**, никогда в `:batch`: они затрагивают всю RPG-базу, а не отдельную строку пакета. См. [[AI - AI Dungeon память и заметки]].

Пакеты не предназначены для `:roll`, `:check`, `:use`, списка без изменений, `:setup`, вложенного `:batch` или `:char create/done`. Некоторые параметры персонажа (`имя`, `пол`, `возраст`, `профессия`) меняются через [[AI - AI Dungeon быстрая настройка|`:setup`]], а не через пакет команд.

## Получение шаблонов

` :batch categories ` — полный перечень категорий; `:help batch` — краткая справка. Для получения встроенного редактируемого шаблона отправь `:batch template КАТЕГОРИЯ`.

| Команда | Что редактируется |
|---|---|
| `:batch template hero` | Все 9 характеристик, биография, мечта |
| `:batch template skills` | Повторяемая строка навыка; пользовательские навыки, привязки |
| `:batch template inventory` | Выдача, изъятие и переименование предметов |
| `:batch template resources` | Деньги, долг, HP, выносливость, голод, жажда, усталость, еда и питьё |
| `:batch template modifiers` | Бафы, дебафы, удаление по ID и массовое снятие |
| `:batch template time` | Календарь, часы, местоположение и отдых |
| `:batch template notes` | Факты, типы заметок, правка, закрепление, удаление |
| `:batch template quests` | Задания, статусы, сроки, изменение, удаление |
| `:batch template rules` | Режимы судьи, переключатели и XP |
| `:batch template review` | Удаление проверенных предложений рассказчика |

## Готовые шаблоны

Все блоки ниже отражают встроенные команды, актуальные для v2.29. **Каждый блок — заготовка, не готовый сценарий выполнения всего подряд.**

### Герой и характеристики — `hero`

Все девять реальных характеристик заполняются по одной. Операции биографии и мечты перечислены полностью; `clear confirm` удаляет текст. Изменение характеристик командой `:stat` сбрасывает соответствующие счётчики XP, как и при одиночном вводе.

```text
:batch
§:stat Сила 10
§:stat Ловкость 10
§:stat Выносливость 10
§:stat Интеллект 10
§:stat Восприятие 10
§:stat Воля 10
§:stat Обаяние 10
§:stat Смекалка 10
§:stat Внешность 10
§:char bio set Краткая биография персонажа
§:char bio add Дополнительное событие из биографии
§:char bio clear confirm
§:char dream set Главная мечта персонажа
§:char dream clear confirm
§:apply
```

### Навыки — `skills`

В комментарии указан **полный список 27 стандартных навыков через `/`**. Под ним только **одна** повторяемая команда `:skill Атлетика 10`. Для изменения нескольких навыков скопируй строку и подставь отдельные названия. Остальные строки — по одной операции создания, смены характеристики, ключевых фраз и удаления **пользовательского** навыка. Сначала создай новый навык, если собираешься его настраивать.

```text
:batch
§# Названия стандартных навыков (выбери одно; / означает ИЛИ): Атлетика / Бдительность / Вождение / Воровство / Выживание / Драка / Запугивание / Компьютеры / Кулинария / Лидерство / Лингвистика / Медицина / Наука / Огнестрельное оружие / Переговоры / Право / Расследование / Ремесло / Скрытность / Технологии / Уличные знания / Финансы / Хитрость / Холодное оружие / Эмпатия / Этикет / Магия
§# Строку :skill можно скопировать столько раз, сколько нужно.
§:skill Атлетика 10
§:skill add Акробатика | Ловкость | акробат, сальто
§:skill attr Акробатика | Ловкость
§:skill bind Акробатика | акробат, сальто
§:skill remove Акробатика
§:apply
```

### Инвентарь — `inventory`

`give`, `take`, `rename` — все операции изменения предметов, поддерживаемые пакетным режимом. `:use` выполняет действие в сюжете и не допускается внутри `:batch`.

```text
:batch
§:give фонарик 2
§:take фонарик 1
§:rename фонарик | фонарь
§:apply
```

### Ресурсы и потребности — `resources`

`hunger`, `thirst`, `fatigue` устанавливают точные значения **0–100** и не двигают время. Они работают даже при `:needs off`. `:needs eat`/`:needs drink` **уменьшают** текущий голод/жажду и требуют включённой системы `needs`. Баланс изменяется со знаком, долг хранится отдельно.

```text
:batch
§:money +100
§:money -10
§:debt set 20
§:debt add 10
§:debt pay 5
§:hp +10
§:hp -5
§:stamina +10
§:stamina -5
§:needs on
§:needs hunger 20
§:needs thirst 30
§:needs fatigue 15
§:needs eat
§:needs drink
§:apply
```

### Временные эффекты d20 — `modifiers`

Включены новые команды `:mod` и совместимые старые команды удаления. Используй **реальные ID**. В одном пакете удаление и добавление исполняются по порядку: освобождённый ID может сразу получить новый эффект.

```text
:batch
§:mod add Скрытность | +2 | 120 | Концентрация
§:mod add Сила | -1 | 60 | Усталость
§:mod remove 1
§:mod clear confirm
§:modifiers remove 1
§:modifiers clear confirm
§:buff remove 1
§:buff clear confirm
§:debuff remove 1
§:debuff clear confirm
§:apply
```

### Календарь, часы и отдых — `time`

`set` устанавливает момент времени без начисления потребностей, `advance` и `:time N` продвигают часы, а отдых влияет на состояние героя. Строки можно выбирать независимо.

```text
:batch
§:date set 2 4 15 09:30
§:date advance 1
§:time set 12:00
§:time 30
§:place Центральная площадь
§:rest 180
§:apply
```

### Заметки и факты — `notes`

В комментарии — **все семь типов заметок**, перечисленные через `/`. `:note add` приводится один раз: выбери тип и копируй строку для остальных записей. `:note Текст` — короткая запись типа «факт». `pin`, `unpin`, `edit` и `remove` требуют действительного ID из `:notes`.

```text
:batch
§# Тип заметки (выбери один; / означает ИЛИ): факт / npc / событие / обещание / место / квест / мир
§:note Краткий факт без указания категории
§:note add факт | Текст записи
§:note edit 1 | Исправленный текст записи
§:note pin 1
§:note unpin 1
§:note remove 1
§:note clear confirm
§:apply
```

### Задания — `quests`

`status` принимает `active / done / failed / cancelled` — нужно оставить **одно** значение. Для изменения, срока и удаления используют актуальные ID из `:quest list all`.

```text
:batch
§# Возможные статусы: active / done / failed / cancelled (выбери один).
§:quest add Найти кузнеца | Узнать, где он работает
§:quest status 1 done
§:quest edit 1 | Новое название | Новое описание
§:quest due 1 | 2 4 15 18:00
§:quest due 1 clear
§:quest remove 1 confirm
§:apply
```

### Режимы и правила — `rules`

В шаблоне перечислены все поддерживаемые пакетные настройки, включая `:judge` и XP. Для `:xp speed` можно оставить пресет `slow` (×0,5), `normal` (×1), `fast` (×2) или вписать собственный множитель, например `:xp speed 1.5` (×1,5). Указанные значения — только образцы. Не включай одновременно несовместимые функции, например `:auto narrative` и `:ledger on`.

```text
:batch
§# Режим auto: on / off / classic / smart / narrative / cautious (выбери один).
§:auto classic
§:magic on
§:ledger on
§:debug off
§:editor on
§:inventory on
§:needs on
§:combat on
§:economy on
§:fallback safe
§:xp on
§:xp mode rest
§:xp speed normal
§:xp apply
§:judge combo weighted
§:judge override Ловкость | Скрытность
§:judge clear
§:apply
```

### Проверка предложений рассказчика — `review`

`dismiss ID` убирает конкретное напоминание, `clear confirm` — все. Обе операции не изменяют деньги или задания.

```text
:batch
§:review dismiss 1
§:review clear confirm
§:apply
```

## Повторение строк и проверка

- Получи шаблон, удали ненужные строки и замени данные / ID. Если нужен второй навык, предмет или факт, скопируй строку соответствующей операции; одна операция в образце не ограничивает количество повторов.
- Общее число исполняемых команд после копирования должно оставаться **не более 20**. Если больше — отправляй несколько отдельных пакетов. Лимит скрипта **не увеличен**.
- Если пакет отклонён, посмотри указанную ошибочную строку, исправь её и отправь пакет заново. При отказе **состояние не изменяется**.
- После успеха проверь `:status`, `:needs status`, `:mod`, `:notes`, `:quest list all`. Повторно не применяй пакет с `add`, `money +`, `give` или продвижением времени без проверки — операции накапливаются.

> [!note] Внешние операции
> `:aidm export` **не поддерживается в `:batch`**. Экспорт Story Card — внешнее действие, не подчиняющееся откату RPG-сохранения. Выполняй его отдельно после применения пакета. См. [[AI - AI Dungeon интеграция с AID Memory Engine]].
