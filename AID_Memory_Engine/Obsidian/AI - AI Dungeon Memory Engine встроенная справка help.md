# AI Dungeon — Memory Engine: встроенная справка `;mem help`

[[AI - AI Dungeon Memory Engine оглавление]] · [[AI - AI Dungeon Memory Engine обновления]] · [[AI - AI Dungeon Memory Engine все команды]] · [[AI - AI Dungeon Memory Engine поля и влияние]]

> [!info] Тематическая справка
> Встроенная справка теперь разбита на тематические разделы, как у Universal RPG. Вызов **не изменяет игровую память**. Основной префикс — `;mem`; сохранена совместимость с `!mem` и `:mem` при прямой отправке таких команд. Символ `;` следует проверить на горячие клавиши в своём интерфейсе AI Dungeon.

> [!tip] Если не работает даже Help
> В версии 1.4.1 используй `;mem ping`, чтобы проверить работу `Library.js` и `Input.js`. Тексты встроенной справки находятся в **Input.js**; обновляй его вместе с Library. При полном отсутствии реакции см. [[AI - AI Dungeon Memory Engine диагностика и ограничения]].


## Help по отладке

` ;mem help debug ` — описание отладки, в том числе `;mem debug on`, `;mem debug full`, `;mem debug last`, `;mem debug context` и `;mem debug off`. Непосредственная команда `;mem debug status` сообщает включённый режим без изменения настроек. Debug не включает автоматическое принятие памяти и не передаёт заметки RPG повторно.


## Быстро

- `;mem help` — меню тем, без десятков строк всех параметров.
- `;mem help all` — краткий полный указатель команд.
- `;mem help start` — минимальная инструкция игроку.
- `;mem help char` — поля персонажа, просмотр и изменение.
- `;mem help place` — родительская локация, `kind`, `status`, карта.
- `;mem help rel` — направленные отношения и `trust`.
- `;mem help plan` — календарь, ежегодные события и ID.
- `;mem help batch` / `;mem batch help` — полный формат пакета и ограничения.

## Справка по сбросу

**`;mem help reset`** или **`;mem help сброс`** объясняет режимы `data`, `cards`, `all`, обязательный `confirm`, фильтр собственного маркера и ограничения API. Предпросмотр без удаления: `;mem reset` (всё), `;mem reset data` (база с разбивкой по видам), `;mem reset cards` (свои Story Cards по типам), `;mem reset all` (оба списка). Числа пересчитываются каждый раз. Полное описание: [[AI - AI Dungeon Memory Engine все команды#Полный сброс памяти и Story Cards]].

## Шаблоны, доступные из Help

`;mem batch template char/skill/rel/place/faction/world/fact/event/day/arc/plan/delete/all` выдаёт готовые пакеты с обычными командами внутри. Например, `;mem batch template rel` показывает обе стороны отношения, а `;mem batch template place` — вложенные места. Старые шаблоны: `;mem batch template legacy char/place/faction/arc/all`.

Раздел `;mem help batch` объясняет, почему в режиме Do рекомендуется `§;mem ...` вместо обычных переносов, и как безопасно откатить пакет.

## Что показано в каждом разделе

Текст состоит из **формата команды**, объяснения полей, **готовых примеров**, сопутствующих команд просмотра/удаления и реальных ограничений. В частности, раздел `place` объясняет, что `parent` требует существующего родителя, `kind` — описательная метка, а `status` не блокирует перемещения.

## Факты и просмотр импортированных карточек

- `;mem list fact` — список фактов с ID, названием и короткой выдержкой.
- `;mem show fact 12` — полный текст факта №12 и его источник.
- `;mem import` — переносит Character/Location/Faction в их сущности, **остальные типы Story Cards — в факты**, не удаляя исходные карточки.

## Режим Do и префикс

Вводи команды отдельными действиями:

```text
;mem help
;mem help персонажи
;mem help карта
;mem help пакет
;mem batch template char
```

С версии 1.3.1 завершающая точка, добавленная режимом Do, учитывается в `;mem world.`, `;mem list char.`, `;mem list place.` и командах просмотра. Команды со старым `!mem` в коде распознаются, но `!` на клавиатуре может активировать горячую клавишу Story. `:mem` может перехватываться Universal RPG. Поэтому для новых команд рекомендуется `;mem`.

> [!warning] Служебные запросы
> `;mem help` заменяет художественный ответ технической справкой, однако не обязательно предотвращает вызов модели и расход игрового хода в AI Dungeon. Используй отдельно от сюжетного действия.

## Новая тема `;mem help import` (v1.5.0)

` ;mem help import ` содержит примеры импорта Story Cards с произвольным типом, Plot и снимка Universal RPG. Русские команды `;mem help импорт`, а также темы `plot` и `rpg`, ведут к тому же разделу. Основные команды `;mem import`, `;mem import plot auto`, `;mem import rpg card` описаны также в [[AI - AI Dungeon Memory Engine все команды#Импорт источников v1.5.0]].

## Проверка автопамяти (v1.6.0)

`;mem help review` или `;mem help проверка памяти` — получение полного порядка проверки; `;mem review`, `;mem review ID`, `;mem accept ID`, `;mem edit ID | значение`, `;mem reject ID`, `;mem review log`, `;mem sources char Имя`.
