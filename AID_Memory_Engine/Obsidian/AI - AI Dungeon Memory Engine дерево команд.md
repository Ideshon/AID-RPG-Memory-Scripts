# Memory Engine — дерево команд

Все команды вводятся отдельным сообщением в режиме Do. Основной префикс — `;mem`; также принимаются `!mem` и `:mem`. В примерах `ID` означает числовой номер записи, `|` разделяет поля. Подробности и ограничения: [[AI - AI Dungeon Memory Engine все команды]].

- **Справка и диагностика**
  - `;mem` / `;mem help` — открыть встроенную справку.
  - `;mem help all` / `;mem help Тема` — общий указатель или справка по теме; доступны и русские названия тем.
  - `;mem ping` — проверить загрузку Library и Input.
  - `;mem status` — показать режимы, счётчики и состояние памяти.
  - `;mem validate` — проверить вложенность мест и ссылки на родителей.
  - `;mem debug` / `;mem debug status` — показать состояние отладки.
    - `;mem debug on` — включить технические сообщения после ходов.
    - `;mem debug full` — включить полный вывод добавления в контекст.
    - `;mem debug off` — выключить отладочные сообщения.
    - `;mem debug last` — показать отчёт последнего хода.
    - `;mem debug context` — показать последний текст, добавленный Memory Engine в контекст.
- **Режимы и текущий мир**
  - `;mem auto on/off` — включить или выключить автоматическое извлечение сведений.
  - `;mem cards on/off` — включить или выключить синхронизацию собственных Story Cards.
  - `;mem cards audit` — найти пользовательские карточки с теми же сущностями, что в памяти.
  - `;mem cards adopt INDEX` / `;mem cards adopt INDEX confirm` — показать замену и передать ручную карточку Memory Engine; вместо `INDEX` введи число после `#` из `audit`.
  - `;mem cards remove-own TYPE Имя` / `... confirm` — убрать дублирующую собственную карточку после предпросмотра.
  - `;mem cards extra TYPE Имя` / `;mem cards extra TYPE Имя | Текст` / `| -` — показать, заменить или очистить дополнительные строки из ручной карточки.
  - `;mem cards backups` / `;mem cards backup TYPE Имя` — показать сохранённые исходные карточки и полный текст копии.
  - `;mem cards restore TYPE Имя` / `... confirm` — вернуть исходную карточку после предпросмотра.
  - `;mem date on/off` — включить или скрыть календарь Memory Engine для рассказчика; записи сохраняются.
  - `;mem date YYYY-MM-DD [HH:MM]` — установить дату и, при необходимости, время памяти.
  - `;mem here` / `;mem here Место` — показать или указать текущее место.
  - `;mem world` / `;mem world Описание` — показать или заменить описание мира.
  - `;mem map` — показать дерево мест и список фракций.
- **Сущности памяти**
  - `;mem char Имя` — показать персонажа.
    - `;mem char Имя | bio=... | traits=... | appearance=... | skills=... | occupation=... | at=...` — создать или изменить его описательные поля.
  - `;mem skill Имя | Навык | Уровень [| Комментарий]` — сохранить описательный навык персонажа.
  - `;mem skills Имя` — показать его отдельные навыки.
  - `;mem place Название` — показать место.
    - `;mem place Название | description=... | parent=... | kind=... | status=...` — создать или изменить место.
  - `;mem faction Название` — показать фракцию.
    - `;mem faction Название | description=... | territory=... | goal=... | status=...` — создать или изменить фракцию.
  - `;mem rel А -> Б | view=... | reason=... | tags=... | trust=...` — создать или изменить отношение А к Б.
  - `;mem arc Название` — показать сюжетную линию.
    - `;mem arc Название | summary=... | status=... | result=... | start=... | end=...` — создать или изменить её.
- **Факты и летопись**
  - `;mem fact Тема | Текст` — добавить устойчивый факт с ID; подходит для сюжетной заметки.
  - `;mem edit fact ID | Новый текст` — заменить текст факта с сохранением ID.
    - `;mem edit fact ID | Новая тема | Новый текст` — заменить также тему факта.
  - `;mem event Описание [| 1..3]` — записать событие на текущую дату.
    - `;mem event YYYY-MM-DD | Описание [| 1..3]` — записать событие на указанную дату.
  - `;mem summary YYYY-MM-DD | Итог` — записать итог дня.
  - `;mem day` / `;mem day YYYY-MM-DD` — показать события, итог и планы текущего или выбранного дня.
  - `;mem timeline` — показать летопись и важные сюжетные линии.
  - `;mem plan YYYY-MM-DD | Заголовок [| Примечание]` — добавить план в календарь.
    - `;mem plan YYYY-MM-DD | Заголовок | Примечание | yearly` — добавить ежегодный план.
  - `;mem calendar` — показать календарные планы.
- **Просмотр и удаление**
  - `;mem list char/place/faction/rel/arc/fact` — перечислить записи одной или нескольких категорий; категории можно разделить `/`.
  - `;mem show char/place/faction/arc Название` — открыть одну сущность.
  - `;mem show rel А -> Б` — открыть направленное отношение.
  - `;mem show fact ID` — открыть факт и его источник.
  - `;mem delete char/place/faction/arc Название` — удалить сущность по имени.
  - `;mem delete rel А -> Б` — удалить одно направление отношения.
  - `;mem delete skill Имя | Навык` — удалить описательный навык персонажа.
  - `;mem delete event/fact/plan ID` — удалить запись по числовому ID.
  - `;mem recent` — показать сырые фрагменты последних сцен.
- **Предложения рассказчика**
  - `;mem pending` / `;mem review` — показать предложения и наблюдения, ещё не внесённые в память.
  - `;mem review ID` — открыть предложение и его источник.
  - `;mem review log` / `;mem review history` — показать последние решения.
  - `;mem edit ID | Новый текст` — исправить предложение в очереди; не меняет подтверждённый факт.
  - `;mem accept ID` — подтвердить предложение.
    - `;mem accept ID replace` — явно заменить защищённое ручное или импортированное значение.
  - `;mem reject ID` — отклонить предложение.
  - `;mem sources char Имя` / `place Название` / `rel А -> Б` — показать происхождение полей.
- **Импорт источников**
  - `;mem import preview` — показать доступные Story Cards и Plot-поля без записи.
  - `;mem import` — импортировать новые Story Cards и доступные Plot-поля.
  - `;mem import refresh` — перечитать ранее импортированные Story Cards; обновить название и текст связанного факта без смены ID.
  - `;mem import plot` — показать справку по Plot.
    - `;mem import plot auto` — прочитать доступные Plot Essentials и Author's Note.
    - `;mem import plot essentials/context/summary/storysummary/authorsnote/note/instructions/ai | Текст` — вручную сохранить соответствующее Plot-поле; некоторые названия являются синонимами.
    - `;mem import plot status` — показать сохранённые Plot-поля.
  - `;mem import rpg` — показать инструкцию по обмену с Universal RPG.
    - `;mem import rpg card` — импортировать обменную Story Card RPG.
    - `;mem import rpg paste | {JSON}` — импортировать вручную вставленный снимок RPG.
    - `;mem import rpg status` — показать импортированный снимок.
    - `;mem import rpg calendar` — перенести дату и время снимка в календарь Memory Engine, если дата допустима.
    - `;mem import rpg notes` — перенести старые RPG-заметки в факты без дубликатов.
- **Пакеты команд**
  - `;mem batch help` / `;mem help batch` — показать формат и ограничения пакета.
  - `;mem batch template char/skill/rel/place/faction/world/fact/event/day/arc/plan/delete/all` — получить готовый шаблон.
  - `;mem batch template legacy char/place/faction/arc/all` — получить совместимый старый шаблон полей.
  - `;mem batch` + строки `§;mem ...` + `§:apply` — применить несколько обычных команд одним блоком.
  - `;mem batch [char/place/faction/arc Имя]` + строки `§поле=значение` + `§:apply` — применить пакет полей старого формата.
- **Перенос в другое приключение**
  - `;mem transfer help` / `;mem transfer ?` — показать инструкцию переноса.
  - `;mem transfer export` / `;mem transfer export all` — подготовить снимок подтверждённой памяти.
    - `;mem transfer export world` — подготовить только мир, места, фракции, факты и Plot.
  - `;mem transfer part N` — получить одну часть снимка для копирования.
  - `;mem transfer import ID N/TOTAL ДАННЫЕ` — принять часть снимка в другом приключении.
  - `;mem transfer` / `;mem transfer status` — показать принятые части и готовность.
  - `;mem transfer apply` — проверить целостность и показать предпросмотр.
    - `;mem transfer apply confirm` — применить снимок к пустой базе.
    - `;mem transfer apply replace confirm` — заменить непустую базу.
  - `;mem transfer cancel` — удалить временные части и подготовленный экспорт.
- **Откат и сброс**
  - `;mem undo` — откатить последний доступный пакет изменений.
  - `;mem reset` / `;mem reset data/cards/all` — показать предпросмотр очистки базы, собственных карточек или всего вместе.
    - `;mem reset data confirm` — очистить базу Memory Engine.
    - `;mem reset cards confirm` — удалить собственные Story Cards.
    - `;mem reset all confirm` — удалить собственные Story Cards и очистить базу.

`§:apply` — завершающий маркер пакета, а не отдельная обычная команда. RPG ведёт квесты через `:quest`; Memory Engine хранит сюжетные факты и заметки.
